# ClientHub CRM: data processing terms (summary)

Fictional. For demo use only.

| Item | Terms |
|---|---|
| Parties | Lumen Outdoor AB (customer, controller) and ClientHub AB (processor) |
| Service | Cloud CRM: contacts, deals, email history |
| Personal data | Contact details, company, purchase history, email correspondence |
| Data subjects | Customers and prospects |
| Hosting | EU only: Frankfurt and Dublin regions |
| Support access | EU-based staff only |
| Sub-processors | CloudHost Europe GmbH (infrastructure, EU); MailRelay SE AB (email delivery, EU) |
| Sub-processor changes | 30 days' written notice; customer may object |
| Retention | Customer data kept for the contract term. Deleted within 30 days after termination unless the customer instructs otherwise |
| Security | Encryption at rest and in transit, role-based access, annual penetration test, ISO 27001 certified |
| International transfers | None |
| Audit rights | Yes, once a year on 30 days' notice |
