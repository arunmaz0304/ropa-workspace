# HelpPilot AI: data processing terms (summary)

Fictional. For demo use only.

| Item | Terms |
|---|---|
| Parties | Lumen Outdoor AB (customer) and HelpPilot AI Ltd (processor, acting on Lumen's instructions) |
| Service | AI chat assistant answering customer questions on Lumen's website, with handover to human agents |
| Personal data | Chat transcripts, email address and order number if the customer provides them |
| Data subjects | Customers and website visitors |
| Hosting | Ireland (EU) for the application and transcripts |
| AI model provider | Third-party large language model provider, inference hosted in the United States |
| Support access | EU-based staff only |
| Sub-processors | CloudHost Europe GmbH (EU); LLM provider (United States) |
| Sub-processor changes | 30 days' written notice |
| Retention | Transcripts kept 12 months by default. The customer can configure a different period |
| Model improvement | HelpPilot may use anonymised transcripts to improve its models unless the customer opts out in the admin settings. Opt-out is off by default |
| Security | Encryption, access controls, SOC 2 Type II report available on request |
| International transfers | LLM provider in the United States. Contract refers to Standard Contractual Clauses. No copy attached |
| Audit rights | SOC 2 report in place of on-site audit |
