# PayLedger Nordic: data processing terms (summary)

Fictional. For demo use only.

| Item | Terms |
|---|---|
| Parties | Lumen Outdoor AB (customer, controller) and PayLedger Nordic AB (processor) |
| Service | Payroll calculation, payslips, reporting to authorities |
| Personal data | Name, personal ID number, bank account, salary, absence, tax details |
| Data subjects | Employees |
| Hosting | Sweden |
| Support access | Tier 1 support from Sweden. Tier 2 support from the vendor's partner in the United States, with remote access to customer data when escalated |
| Sub-processors | NordCloud AB (hosting, Sweden); SupportBridge Inc. (tier 2 support, United States) |
| Sub-processor changes | 14 days' written notice |
| Retention | Payroll data kept for the contract term and up to 7 years afterwards, or as instructed in writing |
| Security | Encryption, multi-factor authentication for vendor staff, access logging |
| International transfers | Transfer to SupportBridge Inc. is covered by Standard Contractual Clauses, referenced in the contract. The signed copy and any transfer assessment are not attached |
| Audit rights | Yes, on request |
